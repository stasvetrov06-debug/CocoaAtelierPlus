# Cocoa Atelier Plus

Подсистема учета материалов для производства ремесленного шоколада.
Демонстрационный экзамен, вариант В9.

## Состав

- `CocoaAtelierPlus.sln` — решение для Visual Studio.
- `CocoaAtelierPlus/` — исходный код приложения (ASP.NET Core MVC, C#).
- `CocoaAtelierPlus/CocoaAtelierDB.sql` — скрипт базы данных (SQLite, 3НФ).
- `CocoaAtelierPlus/publish/` — исполняемые файлы приложения.
- `ER_diagram_CocoaAtelierPlus.pdf` — ER-диаграмма базы данных.

## Запуск

Из папки `CocoaAtelierPlus`:

```
dotnet run
```

Или запустить `publish\CocoaAtelierPlus.exe`.

При первом запуске база данных `CocoaAtelier.db` создается автоматически из скрипта
`CocoaAtelierDB.sql` в папке приложения. Если файл базы удален или поврежден, при
следующем запуске он создается заново. Скрипт можно выполнить и вручную в любой программе
для работы с SQLite: при повторном выполнении база пересоздается, данные загружаются из скрипта.

Приложение открывается по адресу `http://localhost:5079` (запуск из Visual Studio или
`dotnet run`) либо `http://localhost:5000` (запуск `publish\CocoaAtelierPlus.exe`).

## Учетные записи

| Логин | Пароль | Роль |
| --- | --- | --- |
| user01 | 12345 | Пользователь |
| user02 | 12345 | Пользователь |
| manager01 | 12345 | Менеджер |
| manager02 | 12345 | Менеджер |
| admin01 | 12345 | Администратор |

Пользователь просматривает материалы, продукцию и поставщиков. Менеджер дополнительно
добавляет и редактирует материалы. Администратор управляет поставщиками и учетными записями.
